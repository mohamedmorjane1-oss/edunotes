# EduNotes – النقط والملاحظات

تطبيق ويب لرصد نقط المراقبة المستمرة وملاحظات الأستاذ في ملفات الإكسيل المصدَّرة من مسار، ثم تحميل الملف بالاسم نفسه لإعادة استيراده إلى مسار.

- يعمل في الهاتف والحاسوب، ويمكن تثبيته كتطبيق على الشاشة الرئيسية.
- يعمل دون أنترنيت بعد الفتح الأول.
- لا تخرج أي معطيات من الجهاز: الملفات والنقط تبقى في المتصفح فقط.
- يتعرّف وحده على الابتدائي (/10) والإعدادي والثانوي (/20).

## محتوى المجلد

| الملف | دوره |
|---|---|
| `index.html` | التطبيق |
| `jszip.min.js` | مكتبة قراءة ملفات الإكسيل (محلية، ليعمل التطبيق دون أنترنيت) |
| `manifest.json` | بيانات التثبيت كتطبيق (الاسم، الألوان، الأيقونات) |
| `sw.js` | يحفظ التطبيق في الجهاز ليعمل دون أنترنيت |
| `icons/` | أيقونات التطبيق |
| `.nojekyll` | يمنع GitHub من تعديل الملفات |

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً عاماً (Public) باسم `edunotes`.
2. ارفع **كل محتوى هذا المجلد** إلى جذر المستودع (Add file ← Upload files)، مع مجلد `icons` وملف `.nojekyll`.
3. من Settings ← Pages: اختر Source = `Deploy from a branch`، ثم Branch = `main` والمجلد `/ (root)`، ثم Save.
4. بعد دقيقة أو دقيقتين يصبح التطبيق على الرابط:
   `https://اسم-حسابك.github.io/edunotes/`

## التثبيت كتطبيق

- **أندرويد (Chrome):** افتح الرابط ← القائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **الحاسوب (Chrome أو Edge):** أيقونة التثبيت في شريط العنوان.

## عند التحديث

1. عوّض `index.html` بالنسخة الجديدة.
2. في `sw.js` غيّر رقم السطر `const VERSION = "edunotes-v12-1";` (مثلاً إلى `edunotes-v12-2`) حتى تحصل الأجهزة على النسخة الجديدة.
